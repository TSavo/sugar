# LSP Auto mode (#4007) — client-side lift-on-demand

**Status:** cold-pool + shipped-first + disk-durable cache  
**Issue:** https://github.com/TSavo/sugar/issues/4007  
**Law:** Solve reads zero project FS. Auto mode is a property of the **warm LSP client**.

## User path

```text
pip install some_lib
# open a file that imports some_lib
# LSP: cold pool entry only → prefer shipped .proof → disk cache → mint
```

## Seal order (per cold import)

1. **Warm** — module already sealed this process / speaker in base pool → skip  
2. **Process cache** — hit by `source_cid` → free  
3. **Vendor-shipped `.proof`** under package (`.sugar/imports`, `.sugar`, tree) → load as vendor  
4. **Disk auto cache** — `project/.sugar/imports/auto/<source_cid_token>.proof`  
5. **Mint** from source via real python kit → persist to disk auto cache  

Empty mint → zero contracts (honest empty); module marked sealed so we do not re-mint forever.

## Controls

| Env | Effect |
|-----|--------|
| `SUGAR_LSP_AUTO_LIFT=0` | disable |
| unset | **enabled** |
| `SUGAR_LSP_AUTO_TMP` | staging dir for mint |
| `PYTHON` | resolve + lift interpreter |

## Caps

- Max 40 `.py` files / ~1.5MB staged per mint  
- Prefer package `tests/` when present  
- Max 8 shipped proofs scanned  

## DoD

| DoD | Status |
|-----|--------|
| Only cold / unresolved pool entry | **yes** (skip warm/sealed) |
| Prefer shipped `.proof` | **yes** (before mint) |
| Second ref free (source CID) | process + **disk** durable |
| Solve FS = 0 | client only |
| Empty → zero rows | yes |
