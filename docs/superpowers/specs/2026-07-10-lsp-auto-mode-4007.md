# LSP Auto mode (#4007) — client-side lift-on-demand

**Status:** MVP on `sugar-lsp` in-process path  
**Issue:** https://github.com/TSavo/sugar/issues/4007  
**Law:** Solve reads zero project FS. Auto mode is a property of the **warm LSP client**.

## User path

```text
pip install some_lib
# open a file that imports some_lib — no .proof shipped
# LSP auto-lifts vendor source → seals proof by source CID → re-solves
```

## Implementation (MVP)

| Piece | Location |
|-------|----------|
| Import scan | `sugar-lsp/src/auto_mode.rs` — `extract_top_level_imports` |
| Resolve | `python -c importlib.util.find_spec` → package dir |
| Stage + mint | throwaway project + real `sugar_lift_py_tests.lift_rpc` |
| Cache | process-wide map **source_cid → proof bytes** |
| Feed | merge vendor-stamped `ProofBytes` into working base pool; rebuild index |
| Solve | existing `verify_consistency_scoped_with_base_index` |

### Controls

| Env | Effect |
|-----|--------|
| `SUGAR_LSP_AUTO_LIFT=0` | disable |
| unset / other | **enabled** (default on) |
| `SUGAR_LSP_AUTO_TMP` | staging dir (default: temp_dir) |
| `PYTHON` | interpreter for resolve + lift |

### Caps

- Max 40 `.py` files / ~1.5MB per vendor  
- Prefer `tests/` under package when present  

## DoD mapping

| DoD | MVP |
|-----|-----|
| Unresolved → lift-on-demand | On every solve of a buffer with imports (eager auto on imports; refinement = only when cold) |
| Second ref = pool hit | `AUTO_CACHE` by source CID |
| Solve FS = 0 | site-packages only in `auto_mode` client |
| Truth / lie / empty | Same mint membrane; empty mint → zero contracts (honest) |

## Not in this MVP

- Disk-durable auto cache under `.sugar/imports/auto/`  
- Allowlist / only-on-unresolved (eager on all imports today)  
- CLI parity (intentionally none)  
- Full site-packages of pandas without caps
