# Python sole construction law

**Direction:** close Python by draining only failures that pass through the
existing Sugar construction algebra. Never optimize the corpus count directly.

## Governing rule

```text
Source shape
  → registered Sugar owns it
  → factory constructs that Sugar and its SugarBody children
  → Sugar reduces through floor dispatch
  → cited value or genuine typed runtime effect

No owner
  → FactoryPanic
```

No other outcome is permitted.

## How every frontier is fixed

For each fresh recensus owner:

1. Reproduce one exact corpus panic.
2. Identify the **first missing semantic owner** — not the last stack-frame symptom.
3. Decide constructible vs runtime vs unsupported.

**Constructible:** create/extend Sugar; `ctx.build_body` for children; floor
double-dispatch; truthful + lying twins; typed-red witness if runtime effect;
confirm corpus panic gone.

**Genuinely runtime:** keep Sugar owner; specific typed effect with runtime
operand; red-effect witness + bad twin. **Never** generic `RuntimeEffect` as
“unknown construction.”

**Unsupported:** narrow `owns()`; factory finds no candidate; preserve
`FactoryPanic`. That last option is honorable. An invented effect is not.

## Forbidden PR shapes

- Catch `FactoryPanic` and continue (except audit membrane → loud red row).
- Convert construction gap into `Incomplete`, opacity, empty collection, missing row.
- Soft-default around gaps (`try/except`, `getattr(..., default)`, `None`).
- Construct IR/floor/temporal/testimony in `factory/`, `recognition/`, RPC, report, or corpus tooling (except allowed audit membrane).
- Semantic AST interpretation outside a registered Sugar owner.
- Broaden `owns()` without twins for every new partition.
- Vendor special-case (numpy/pandas/datetime class/name matchers).
- Shrink census by skipping files, assertions, descendants, or timeouts.
- Update a baseline to green nonzero R.

## Fleet execution order

1. Finish #5234 — every corpus file terminates: completed | typed red | panic | bare | crash | timeout.
2. Complete #5233 — one conserved post-Sugar-only vector.
3. Close or recensus every issue based on old `320b87cc` owner counts.
4. Dispatch new owner buckets in **descending mass**.
5. Reserve one lane continuously for **side-door auditing**, not frontier implementation.
6. Re-run full recensus after each major owner family — not every small PR.
7. When panic mass is zero, run all declared walls (numpy, pandas, scipy, sklearn, pydantic, SQLAlchemy, cryptography, requests, datetime, logos).
8. Declare completion only after **two consecutive content-pinned runs** report:

```text
Factory side doors  = 0
Ownership gaps       = 0
Silent lines         = 0
Construction panics  = 0
Bare exceptions      = 0
Native crashes       = 0
Timeouts             = 0
Every source line    = warranted | support | inert | typed effect
```

## Management rule

**Fleet workers own Sugar families, not corpus files.**  
Corpus files are witnesses. Organizing by files encourages vendor special cases;
organizing by semantic owners produces reusable construction and drains numpy,
pandas, and every other logo together.
